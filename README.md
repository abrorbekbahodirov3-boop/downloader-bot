
# Telegram Downloader Bot - Copyright Safe

## 24/7 bepul hosting - Koyeb (tavsiya)

1. Bu papkani GitHub ga yuklang (private repo qiling)
2. koyeb.com da ro'yxatdan o'ting (GitHub bilan)
3. Create App -> GitHub repo tanlang -> Dockerfile builder avtomatik
4. Environment Variables bo'limida:
   Key: BOT_TOKEN
   Value: sizning tokeningiz
5. Deploy bosing - 2 daqiqada 24/7 ishlaydi

## Alternativ - Render.com
- render.com da Web Service yarating
- Start command: python bot.py
- Env: BOT_TOKEN qo'shing
- Free tier uxlab qoladi, shuning uchun uptimerobot.com da har 10 daqiqada ping qiling
